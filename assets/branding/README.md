# Nummio Brand Kit v1.0

Marca: **Nummio** · `nummio.dev`
Assinatura: **Curiosity, engineered.**

## Pastas
- `logo/`: wordmarks SVG vetorizados e PNG transparente (claro, escuro, monocromático).
- `icons/`: símbolos, favicons, ícones em múltiplos tamanhos e `.ico`.
- `imagery/`: 3 artes conceituais (1600×1000) Classical Intelligence, Computational Forms, Constructed Forms.
- `social/`: Open Graph 1200×630 e banner GitHub 1500×500.
- `system/`: tokens JSON/CSS e guidelines Markdown.

**Nota:** Arte conceitual e estudos de identidade ainda não substituem auditoria de propriedade intelectual, registro de marca ou teste completo de acessibilidade. Fotos e referências históricas reais devem ter autorização de uso. As imagens do kit são estudos artísticos, não documentação de obras reais.
